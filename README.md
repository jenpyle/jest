# Jest Practice

Practice testing JavaScript array functions with Jest.

## Setup

```sh
npm install
```

## Run tests

Run all tests:

```sh
npm test
```

Run tests in one folder:

```sh
npx jest filter/
```

## Folder layout

- `filter/`: `removeOddNumbers.js` (function) and `test.js` (tests).
- `forEach/`: `sum.js` (function) and `test.js` (tests).

Babel uses `.babelrc` to transpile ES module imports for Jest.
